Importer :
ⓘ Mot ou expression ?
Comment l'import décide :
  1. Une colonne « Type » (mot / expression) dans le tableau : elle fait foi.
  2. Sinon : un espace entre les caractères (我 爱 屋家) ou plus de 6 caractères → expression ; sinon → mot.
  3. Lecture par l'IA (texte collé, lecture complète) : l'IA indique elle-même « mot » ou « expression ».
  4. Une expression écrite d'un bloc (做生理人) est découpée en mots du lexique, le plus long d'abord : 做生理 人 / zo4sen1li1 ngin2. Un caractère sans mot connu reste seul.
  5. Un mot est toujours enregistré sans espace.
Les mots inconnus d'une expression importée ne sont pas ajoutés d'office : ouvrez-la dans la Saisie (✎) pour les proposer avec elle. Dans l'aperçu, les deux onglets « Mots » et « Expressions » séparent ce qui a été reconnu ; ce qui n'est pas demandé est écarté.

✨ Après chaque lecture, l'IA vérifie automatiquement que le français est en français et l'anglais en anglais (une petite requête).
